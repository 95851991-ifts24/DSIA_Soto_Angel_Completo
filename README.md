# Desarrollo de Sistemas de Inteligencia Artificial - 2026

**Estudiante:** Soto, Angel

---

## Breve Descripción de la Materia
Desarrollo de Sistemas de Inteligencia Artificial es una asignatura orientada a comprender y aplicar los principios fundamentales para el diseño y desarrollo de soluciones basadas en inteligencia artificial. Se abordan conceptos teóricos y herramientas prácticas vinculadas al análisis de datos, el uso de modelos de aprendizaje automático y la implementación de proyectos de IA en contextos reales. Además, propone reflexionar sobre el impacto tecnológico, social y ético que generan estas tecnologías en la actualidad.

## Aspectos Más Interesantes del Curso
El aprendizaje práctico en entornos colaborativos como Deepnote y la estructuración de flujos de trabajo profesionales utilizando Git y GitHub para proyectos de ciencia de datos.

## Listado de Trabajos Prácticos Realizados

### TP 01: Introducción a Deep Note y Entornos de Trabajo Colaborativos
**Bajada Descriptiva:** En este trabajo práctico se exploró el uso de DeepNote como entorno de desarrollo para proyectos de ciencia de datos. Se trabajó con la creación y organización de notebooks, la ejecución de celdas de código y markdown, y la gestión básica de proyectos dentro de la plataforma.
* **Enlace:** [001-Deepnote/](001-Deepnote/)

### TP 02: Introducción a la Programación en Python
**Bajada Descriptiva:** En este trabajo práctico se abordaron los conceptos fundamentales de programación en Python, incluyendo variables, tipos de datos, operadores, estructuras de control y funciones.
* **Enlace:** [002-PythonIntroduccion/](002-PythonIntroduccion/)

### TP 03: Librerías de Python
**Bajada Descriptiva:** Esta actividad tuvo como objetivo familiarizarse con el ecosistema de librerías de Python utilizadas en Ciencia de Datos (NumPy, Pandas, Seaborn y Matplotlib), explorando la importación de librerías, la manipulación de arreglos numéricos, la creación de DataFrames simples y el análisis de criterios para la selección de herramientas.
* **Enlace:** [003-PythonLibrerias/](003-PythonLibrerias/)

### TP 04: Control de Versiones con Git y GitHub
**Descripción:** Esta actividad tuvo como objetivo introducir el uso de Git y GitHub como herramientas de control de versiones y organización de proyectos de Ciencia de Datos.

Se trabajó en la creación y organización de un repositorio público destinado a almacenar los ejercicios y trabajos prácticos desarrollados durante la materia, incluyendo las actividades de Deepnote, introducción a Python y librerías de análisis de datos.

A diferencia de los demás trabajos prácticos, esta actividad no requirió desarrollar un notebook independiente, ya que el propio repositorio constituye la evidencia de su realización.

**Evidencias:**

- [Ver repositorio público de DSIA 2026](https://github.com/95851991-ifts24/DSIA_Soto_Angel_Completo)
- [Consultar historial de commits](https://github.com/95851991-ifts24/DSIA_Soto_Angel_Completo/commits/main/)

### TP 05: Trabajo Práctico Integrador (TPI)

**Descripción:** Proyecto grupal desarrollado en etapas para aplicar técnicas de ciencia de datos e inteligencia artificial. El equipo comenzó con la exploración y comparación de datasets, seleccionó *Delivery Market Argentina* para profundizar en la limpieza y el análisis estadístico, y posteriormente entrenó y evaluó modelos predictivos del tiempo de entrega. Los datos de Delivery son sintéticos y se utilizan con fines académicos.

**Enlace principal:** [📁 Trabajo Práctico Integrador](./005-TPI-EDA/)
